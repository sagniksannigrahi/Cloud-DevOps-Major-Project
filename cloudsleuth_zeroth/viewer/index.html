When one service breaks, many look broken.
CloudSleuth finds the one that caused it.

It reads metrics, traces, logs, recent changes and database statistics, ranks the likely causes, and shows the evidence for and against its answer. On AWS, this page is deployed by a Jenkins pipeline on every push to GitHub.

▶ Run the live demoSee the results
The problemOne failure, many alarms

In a microservice app, one broken part makes many services look unhealthy at once. Engineers lose time finding the one that actually caused the outage.

Our solutionRank the causes, show the evidence

CloudSleuth reads the telemetry, ranks the likely causes, names the fault type and lists the evidence for and against, so a person can check its reasoning.

The resultFinds the real cause in most cases

Delivered automatically: GitHub → Jenkins → Docker → AWS EC2, with every change tested before it goes live.
